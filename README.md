# 62 pet business website concepts

A collection of 62 independent website concepts for grooming studios and veterinary practices in Moscow and Saint Petersburg.

## Browse

Open `index.html` for the searchable catalogue. Each business has a complete standalone website at `sites/<slug>/`, with its own local images, styles, fonts and scripts.

The catalogue includes links to the business map listing, its existing website or social page, and the new concept. Brief descriptions of the improvements are provided in Russian and English. Public catalogue data is available in `data/sites.json`.

## GitHub Pages

This repository is a static website. In **Settings → Pages**, choose **Deploy from a branch**, the default branch and **/(root)**. The `.nojekyll` file disables Jekyll processing. No build tools, package installation, API keys or backend are required.

All internal assets and catalogue links use relative paths so the collection works on a repository-based GitHub Pages URL or another static host.

## Local preview

Serve this folder with any static HTTP server, then open its root URL. Most content can also be opened directly from `index.html`.

## About these concepts

These are independent design concepts, not the official websites of the listed businesses. Business details were researched from publicly available sources on 19 October 2026. Contact channels and map links point to the existing businesses. Booking and prices must be confirmed by the business.

Animal illustrations were created for the concepts and do not represent photographs of actual patients, grooming results or interiors. Original logos, where confirmed, remain the property of their respective owners. Third-party font licenses are included where supplied.
